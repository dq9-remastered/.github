# DQ9 Remastered

A fan research project around **Dragon Quest IX: Sentinels of the Starry Skies** (Nintendo DS, European release): a native PC port built by static recompilation, a matching decompilation, and a cookbook for doing the same with other DS games.

**No game data is distributed here.** Every project needs your own legally obtained copy of the game; ROMs, extracted assets and saves never leave your machine.

## Repositories

| Repository | What it is | Status |
|---|---|---|
| [DQ9-Remastered](https://github.com/dq9-remastered/DQ9-Remastered) | ARM/Thumb static recompiler, C++ DS runtime, SDL "Classic" host (original gameplay) and Godot "Enhanced" host (widescreen, HD 3D, texture replacement). Source only. | Pre-releases available |
| dq9-decomp | Matching decompilation of the EU game code (C/C++ that rebuilds byte-identical code). | Coming soon |
| nds-recomp-cookbook | Generic guide and runtime base for statically recompiling Nintendo DS games. | Planned |
