  <i>A fan research project around <b>Dragon Quest IX: Sentinels of the Starry Skies</b> (Nintendo DS, European release).</i><br>
  <sub>No game data is distributed here: every project needs your own legally obtained copy of the game.</sub>
</p>

<br>

<table>
  <tr>
    <td width="33%" valign="top">
      <h3><a href="https://github.com/dq9-remastered/DQ9-Remastered">DQ9-Remastered</a></h3>
      <p>The native PC port. An ARM/Thumb static recompiler turns the game code into C++, running on our own DS runtime.</p>
      <ul>
        <li><b>Classic</b> (SDL): original gameplay, frame-exact reference</li>
        <li><b>Enhanced</b> (Godot): widescreen, HD 3D, texture replacement</li>
      </ul>
      <p><a href="https://github.com/dq9-remastered/DQ9-Remastered/releases"><b>Pre-releases →</b></a></p>
    </td>
    <td width="33%" valign="top">
      <h3>dq9-decomp</h3>
      <p>A matching decompilation of the European game code: C/C++ that rebuilds byte-identical code.</p>
      <ul>
        <li>14,660 / 14,794 functions matched</li>
        <li>99.2% of code bytes</li>
        <li>38 / 38 modules verified</li>
      </ul>
      <p><b>Coming soon</b></p>
    </td>
    <td width="33%" valign="top">
      <h3>nds-recomp-cookbook</h3>
      <p>A guide and generic runtime base for statically recompiling other Nintendo DS games, built from what we learned here.</p>
      <ul>
        <li>Recompiler recipes</li>
        <li>Generic DS hardware runtime</li>
        <li>Testing against real behaviour</li>
      </ul>
      <p><b>Planned</b></p>
    </td>
  </tr>
</table>
